# Image Enhancer

This skill improves image and screenshot quality through intelligent processing.

## Key Capabilities

- Analyzes resolution, sharpness, and compression issues
- Intelligently upscales images
- Enhances edges and details
- Removes compression artifacts and noise
- Adapts processing based on intended application

## Primary Use Cases

- Blog and documentation images
- Social media visuals
- Presentation screenshots
- Print materials
- Blurry photos
- Low-resolution images
- Compressed files

## Workflow Example

When processing an image:
1. Analyze current specifications (resolution, sharpness, compression)
2. Apply enhancements (upscaling to retina resolution, sharpening text, optimizing file size)
3. Preserve the original file
4. Save the improved version

## Practical Tips

- Batch process multiple files simultaneously
- Request specific output formats (PNG for quality retention, JPG for smaller files)
- Mention target platform when optimizing for social media
- Works optimally with digital images and screenshots

## Non-Destructive Workflow

The skill maintains archival copies of originals, making it safe for non-destructive enhancement workflows. Original files are never overwritten.
