# File Organizer

This skill is your personal organization assistant, helping you maintain a clean, logical file structure across your computer without the mental overhead of constant manual organization.

## Key Capabilities

- Analyzes folder structures
- Identifies duplicate files
- Proposes logical reorganization schemes
- Automates cleanup tasks with user approval
- Handles file movement, renaming, and archiving
- Preserves context based on content types and modification dates

## Primary Use Cases

- Chaotic Downloads folders
- Scattered files across multiple locations
- Duplicate file accumulation
- Outdated folder hierarchies
- Project startup organization needs

## Operational Approach

The skill follows a structured seven-step methodology:

1. **Clarification** - Gathers scope and constraints through targeted questions
2. **Analysis** - Examines current directory structure and file distribution
3. **Pattern Recognition** - Identifies logical grouping opportunities by type, purpose, or date
4. **Duplicate Detection** - Locates redundant files using hash matching and naming analysis
5. **Planning** - Presents comprehensive reorganization proposals for approval
6. **Execution** - Implements approved changes with detailed logging
7. **Maintenance** - Provides post-organization guidance and recurring task commands

## Notable Features

- Mandatory confirmation checkpoints before file deletion or major restructuring
- Modification date integrity preservation
- Graceful handling of filename conflicts
- Recovery options through comprehensive move logging
- User control at every stage
