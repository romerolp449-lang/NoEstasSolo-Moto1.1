# Meeting Insights Analyzer

This skill is a communication analysis tool that examines meeting transcripts to identify behavioral patterns and communication habits.

## Core Capabilities

1. **Pattern Recognition** - Detects recurring behaviors like conflict avoidance, speaking ratios, question-asking patterns, listening indicators, and decision-making approaches

2. **Communication Analysis** - Evaluates clarity, directness, filler word usage, tone, and meeting control

3. **Actionable Feedback** - Provides timestamped examples showing what happened, why it matters, and improvement strategies

4. **Trend Tracking** - Compares patterns across multiple meetings over time

## Usage Workflow

1. Discover available transcript data
2. Clarify analysis goals
3. Analyze patterns for specific behaviors
4. Provide concrete examples with context
5. Synthesize overall insights
6. Offer follow-up analysis options

## Analysis Focus Areas

- Conflict avoidance detection
- Speaking ratio calculations
- Filler word frequency tracking
- Active listening assessment
- Leadership facilitation evaluation

## Output Format

Analysis results include:
- Findings summaries
- Frequency counts
- Detailed examples with timestamps
- Communication strengths
- Growth opportunities
- Speaking statistics
- Actionable next steps for improvement

## Example Behaviors Analyzed

- Speaking too much or too little
- Avoiding difficult topics
- Not asking clarifying questions
- Missing opportunities to acknowledge others
- Decision-making patterns
