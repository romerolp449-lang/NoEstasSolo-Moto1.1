# Canvas Design

This skill creates museum-quality visual art through a structured creative process.

## Process

### Step 1: Design Manifesto
Establish a design philosophy by creating a manifesto that defines:
- Core visual principles
- Conceptual themes
- Aesthetic direction
- Target emotional impact

### Step 2: Visual Expression
Express the manifesto visually by producing:
- PDFs for print-quality output
- PNGs for digital use
- Minimalist compositions with purposeful negative space
- Sophisticated typographic treatments

## Design Principles

- Minimize text; let visual elements communicate
- Every element should serve the conceptual purpose
- Expert craftsmanship in spacing, proportion, and color
- Conceptual depth over decorative complexity
- Museum-quality standards for composition and finish

## Output Formats

- **PDF**: High-resolution, print-ready documents
- **PNG**: Web and digital-optimized images
- **Both**: When multiple use cases are needed

## When to Use

Use this skill when creating:
- Artistic presentations
- Brand identity pieces
- Visual manifestos
- Conceptual design documents
- Exhibition materials
