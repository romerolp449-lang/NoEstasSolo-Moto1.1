# Twitter Algorithm Optimizer

This skill analyzes and optimizes tweets for maximum reach using Twitter's open-source algorithm insights.

## Core Algorithm Components

Twitter's recommendation system uses four interconnected models:

1. **Real-graph**: Predicts interaction likelihood between users and determines how widely tweets spread to followers and beyond

2. **SimClusters**: Identifies niche communities with shared interests to help tweets resonate within specific groups

3. **TwHIN**: Maps relationships between users and content topics to ensure tweet relevance to follower interests

4. **Tweepcred**: Scores user reputation and authority, affecting current tweet distribution based on engagement history

## Engagement Signals Framework

### Positive Signals (maximize)
- Likes
- Replies
- Retweets
- Quote tweets
- Profile visits (implicit)
- Link clicks (implicit)
- Time spent (implicit)
- Bookmarks (implicit)

### Negative Signals (avoid)
- Blocks
- Reports
- Quick scrolling past

## Six Optimization Strategies

1. **Maximize follower engagement** - Create content your existing followers will interact with
2. **Leverage community resonance** - Target niche communities with relevant content
3. **Improve content-user fit** - Align topics with your follower interests
4. **Boost credibility** - Build Tweepcred through consistent quality
5. **Trigger specific engagement types** - Design content to elicit replies, retweets, or bookmarks
6. **Prevent negative signals** - Avoid content that triggers blocks or reports

## Practical Implementation

For each tweet to optimize:
1. Identify the core message
2. Map it to algorithm strategies
3. Optimize for specific signal triggers
4. Check against potential negative signal risks
5. Refine timing and format
