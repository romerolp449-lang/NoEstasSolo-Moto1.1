# Developer Growth Analysis

This skill analyzes your recent Claude Code chat history to identify coding patterns, development gaps, and growth opportunities.

## When to Use

Request analysis with commands like:
- "Analyze my developer growth from my recent chats"
- "Analyze my work from today and suggest areas for improvement"

## Core Functionality

### Six-Step Process

1. **Chat History Review**: Reads local Claude Code chat data from the past 24-48 hours
2. **Pattern Analysis**: Examines projects, technologies, problem types, and challenges encountered
3. **Gap Detection**: Identifies 3-5 specific, evidence-based improvement areas
4. **Report Generation**: Creates a comprehensive growth report with summaries and recommendations
5. **Resource Curation**: Searches HackerNews for relevant learning materials
6. **Slack Delivery**: Sends the complete report to your direct messages

## Report Contents

Generated reports include:
- Work summary across your recent projects
- Prioritized improvement areas with specific evidence and recommendations
- Identified strengths to build upon
- Actionable next steps
- Curated learning resources from HackerNews tailored to your actual work patterns

## Approach

This skill emphasizes actionable, specific feedback grounded in your actual development work rather than generic guidance, making it ideal for developers seeking data-driven insights into their growth trajectory.
