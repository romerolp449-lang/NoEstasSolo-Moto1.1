# Raffle Winner Picker

This skill provides fair, transparent random selection for giveaways and contests.

## Core Functions

- Cryptographically random winner selection from multiple sources
- Support for Google Sheets, CSV, Excel, and plain text lists
- Multi-winner picking with duplicate prevention
- Weighted selection options and runner-up identification

## Primary Use Cases

- Running social media giveaways
- Picking raffle winners at events
- Randomly selecting participants for surveys or tests
- Choosing winners from contest submissions
- Any selection requiring demonstrated fairness

## Key Features

- Transparent process with timestamp documentation
- Exclusion options for previous winners
- Equal team assignment capabilities
- Export functionality for record-keeping
- Repeatable verification via seed options

## Security and Fairness

- Secure random number generation without bias
- Timestamps recorded for accountability
- Repeatable verification via seed options
- Complete audit trail

## Practical Workflow

1. Paste sheet URLs, upload files, or provide lists directly
2. Specify number of winners needed
3. Set any exclusions (previous winners, etc.)
4. Perform selection
5. Display comprehensive winner details including all relevant entry information
6. Export results for record-keeping
