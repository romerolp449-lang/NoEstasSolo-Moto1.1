# Domain Name Brainstormer

This skill helps generate creative domain name ideas and checks availability across multiple top-level domains.

## Primary Functions

- Analyzes project details to understand context and audience
- Creates relevant, memorable domain suggestions
- Verifies availability across extensions like .com, .io, .dev, .ai, .app, and more
- Offers variations when preferred choices are unavailable
- Provides branding reasoning for name selections

## Use Cases

- Starting new projects
- Launching products
- Creating personal brands
- Rebranding efforts
- Finding alternatives when initial domain choices are registered

## Key Characteristics of Good Domains

Quality domains should be:
- **Short**: Under 15 characters ideal
- **Memorable**: Easy to recall
- **Pronounceable**: Can be spoken clearly
- **Descriptive**: Hints at purpose without being too literal
- **Clean**: No hyphens

## TLD Selection Guide

| TLD | Best For |
|-----|----------|
| .com | General business, universal trust |
| .io | Tech startups |
| .dev | Developer tools and projects |
| .ai | AI products and services |
| .app | Mobile and web applications |

## Practical Workflow

1. Describe your project, audience, and key themes
2. Receive 10-15 suggestions across various TLDs
3. Review availability information
4. Select favorites
5. Register promptly - quality domains are claimed quickly
