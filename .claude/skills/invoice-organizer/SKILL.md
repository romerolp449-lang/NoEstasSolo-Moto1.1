# Invoice Organizer

This skill transforms disorganized financial documents into a structured, tax-ready filing system by automatically organizing invoices and receipts.

## Core Capabilities

1. **Information Extraction**: Reads vendor names, invoice numbers, dates, amounts, and service descriptions from PDFs, images, and documents

2. **File Standardization**: Applies consistent naming using the format `YYYY-MM-DD Vendor - Invoice - ProductOrService.pdf`

3. **Logical Organization**: Sorts files into folders by vendor, expense category, time period, or tax classification

4. **Format Support**: Handles PDFs, scanned receipts (JPG/PNG), email attachments, screenshots, and bank statements

## Workflow Process

1. Scan target folder
2. Extract information from each file
3. Select organizational strategy (vendor, category, time period, tax classification)
4. Standardize filenames
5. Create execution plan
6. Generate CSV report
7. Provide completion summary

## Use Cases

- Tax season preparation
- Expense reconciliation
- Vendor management
- Automated ongoing bookkeeping
- Record archiving
- Reimbursement documentation
- Accountant coordination

## Important Notes

- Original files are preserved while organizing copies
- Multiple organizational patterns available (simple vendor-based to complex quarter-based)
- All changes are logged for accountability
