# Internal Comms

This skill assists with composing various internal communications using company-preferred formats.

## Supported Communication Types

- **3P Updates** (Progress, Plans, Problems) - Team progress updates
- **Company Newsletters** - Organization-wide announcements
- **FAQ Responses** - Answers to common questions
- **Status Reports** - Project and initiative status
- **Leadership Updates** - Executive communications
- **Project Updates** - Team and stakeholder updates
- **Incident Reports** - Post-incident documentation

## Core Workflow

1. Identify your communication type
2. Reference the matching guideline file from the examples directory
   - `3p-updates.md` for team progress updates
   - `company-newsletter.md` for organization-wide announcements
   - Other template files as appropriate
3. Follow the specific instructions for formatting, tone, and content

## Key Feature

When a requested communication format doesn't align with existing guidelines, the skill recommends seeking clarification on the desired structure before proceeding.

The skill emphasizes following specific instructions within each template file regarding:
- Formatting choices
- Appropriate tone
- Information to gather from stakeholders
