# Brand Guidelines

This skill applies Anthropic's official brand identity to artifacts and documents for consistent visual presentation.

## Brand Elements

### Color Palette
- Primary text: `#141413` (dark tone)
- Background: `#faf9f5` (light)
- Accent orange: `#d97757`
- Accent blue: `#6a9bcc`
- Accent green: `#788c5d`

### Typography
- Headings: Poppins (Arial fallback)
- Body text: Lora (Georgia fallback)

## Application Rules

Apply fonts based on text size:
- Larger headings: Poppins
- Body content: Lora
- Fallback when custom fonts unavailable: Arial or Georgia

Visual elements (shapes, decorative components) should cycle through the accent color palette to maintain brand consistency while adding visual variety.

Use RGB values for precise color matching across different platforms.

## Usage

To apply brand guidelines to an artifact:
1. Import or reference the brand color palette
2. Apply correct font families based on content type
3. Use accent colors consistently for visual elements
4. Ensure sufficient contrast for readability
